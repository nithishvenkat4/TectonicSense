# TectonicSense — Project Overview

## 1. Project Title

TectonicSense: Explainable Machine Learning for Tectonic Plate Boundary Classification Using Seismic and Geospatial Features

## 2. Problem Statement

This project investigates whether seismic, spatial, and tectonic features can be used to classify the tectonic environment associated with an earthquake.

## 3. Research Question

How effectively can seismic, spatial, and tectonic features classify earthquake-associated tectonic environments using explainable machine learning?

## 4. Objectives

1. Construct a labeled earthquake–tectonic dataset from authoritative seismic and plate-boundary sources.
2. Engineer seismic, spatial, and tectonic features.
3. Compare baseline and advanced ensemble learning models.
4. Optimize the best-performing model using hyperparameter optimization.
5. Analyze model behavior using explainable AI techniques.
6. Deploy the final inference pipeline through an API and interactive application.

## 5. Scientific Scope

The project focuses on tectonic-environment classification. It does not attempt to predict when or where a future earthquake will occur.
